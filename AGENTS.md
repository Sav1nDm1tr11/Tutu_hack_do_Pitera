# AGENTS.md — правила работы агентов в этом репозитории

`CLAUDE.md` и `.cursor/rules/*` ссылаются сюда. Спека — источник правды,
агент идёт мелкими проверяемыми шагами, человек держит поводок коротким.

## Что читать перед работой

1. `docs/SPEC.md` — контракт продукта.
2. `docs/ARCHITECTURE.md` — слои и границы.
3. `docs/handoff/01-mcp-reference.md` — **проверенный** справочник по Tutu MCP.
4. `docs/wiki/REVIEW-2026-08-19.md` — текущее состояние качества и открытые дефекты.

## Десять правил

1. **Спека главнее мнения агента.** Расхождение с `docs/SPEC.md` — повод спросить,
   а не додумать. Меняется продукт → сначала правится спека.
2. **Один шаг = один коммит = один проверяемый результат.** После каждого шага
   `pnpm test`, `pnpm typecheck`, `pnpm lint`.
3. **Не выдумывай поля MCP.** Разрешены только поля из
   `docs/handoff/01-mcp-reference.md` и `apps/api/src/adapters/inventory/mcp/__fixtures__/`.
   Нет поля — в UI пишем «Туту не вернул это поле», а не подставляем заглушку.
4. **Границы слоёв нерушимы.** `packages/domain` не знает про React, Fastify и MCP SDK.
   Сеть живёт только в `apps/api`. `components/*` без бизнес-логики.
5. **URL Туту непрозрачны.** `checkout_url` и `search_results_url` показываем ровно
   как вернул MCP: не пересобираем, не перекодируем, не режем параметры.
6. **Цены не округляем.** Цена отеля уже за весь период проживания.
7. **Деградируй, не падай.** Отказ одной категории инвентаря не роняет план:
   частичный результат с честным `warning` лучше пустого экрана.
8. **Fixture-режим священен.** `INVENTORY_MODE=fixture` — страховка демо.
   Ломать его нельзя ни одной правкой.
9. **Никаких новых зависимостей** без явного согласия. Стек зафиксирован.
10. **Не рефакторь то, о чём не просили.**

## Что мы не делаем никогда

- Не бронируем и не принимаем оплату: MCP read-only, покупка — по ссылке handoff.
  Deny-list на booking-tool'ы не ослабляется (единственное исключение —
  `create_checkout_link`, это чистый билдер URL без побочных эффектов).
- Не обещаем real-time статусы задержек: их в MCP нет. Считаем **структурную**
  устойчивость и говорим об этом в интерфейсе.
- Не строим чат или голосовой ассистент как основной интерфейс.

## Definition of Done

- [ ] `pnpm test` / `pnpm typecheck` / `pnpm lint` — зелено
- [ ] работает и на живом MCP (`INVENTORY_MODE=live`), и на fixtures
- [ ] пустое и ошибочное состояния нарисованы
- [ ] мобильный вид 390×844 не сломан
- [ ] изменился контракт API → обновлён `docs/SPEC.md`
- [ ] секретов нет: `git grep -iE "sk-or-|secret|api[_-]?key"` пусто
